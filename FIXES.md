## P2 — medium

- **CSP added** (`public/_headers`) with `script-src 'self'`; the remote `accounts.gothwadtech.com/widget/account-menu.js` injection was **removed** — the local shadow-DOM controller is used instead. `theme-init.js` is an external file so no inline-script exception is needed.
- `/assets/*` no longer forces `Content-Type: image/png` onto non-PNG files.
- `X-Frame-Options: DENY` + COOP kept intentionally (SSO is redirect-based, not popup); documented in README as a decision, not an accident.
- SSO hosts now come from `brand.ts` env vars (`VITE_DRIVE_URL`, `VITE_MAIL_URL`), no hard-coded subdomains.
- `X-Gothwad-Authuser` is sent **same-origin only** — no CORS preflight on cross-origin session probes.
- Account switch: single navigation (`location.assign`) instead of `href` + redundant `reload()` 300 ms later; path built with `stripAuthuserPath` instead of chained `replace()`.
- Removed the 92 kB `og-image` preload; fonts now load non-blocking (`preload as="style"` + `noscript` fallback).
- `manualChunks`: `react-vendor` (69 kB gzip) / `icons` / route chunks — app entry is now **13.85 kB gzip**.
- Assets de-duplicated: `public/` went from 1.7 MB / 45 files → **940 KB / 34 files**; references point at the canonical copies.
- `autoFocus` removed, skip-to-content link added, `<main id="main">`, `aria-label` on every nav landmark, decorative icons `aria-hidden`, `aria-live` on the results counter.
- "I'm feeling lucky" (did nothing) replaced with a real search submit.
- `ErrorBoundary` around the lazy routes — a failed chunk shows a reload prompt instead of a blank page.
- Session effect is cancellation-safe; duplicate `preload` call removed.
- Unknown paths render a proper in-app 404 with `noindex`.
